# Zero-Defect Bridge

Conditional.

\[
\boxed{
\Phi(T)=0 \Longrightarrow T\simeq S^3
}
\]

with

\[
\Phi(T)=\sum_{v\in T}|d(v)-6|.
\]

Required new ingredient:
a rigidity theorem converting zero vertex-defect for a closed simply connected triangulated \(3\)-manifold into the spherical model.

Status: Open.
